# بررسی فعال‌سازی فروشگاه حضوری

صفحهٔ ثابت برای بررسی دستی. نام را عوض نمی‌کند و فروشگاهی را فعال نمی‌کند. منطق صف، تطبیق URL، و خروجی CSV داخل خود صفحه است و فایلی همراه برنامه نیست.

## باز کردن

فایل `index.html` را در مرورگر باز کنید، یا از همین پوشه:

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

یا:

```bash
python3 /agent/review-app/server.py
```

سپس http://127.0.0.1:8765

در شروع، سه CSV را خودتان انتخاب کنید: خروجی تب New Flow، online، و social. چیزی به سرور فرستاده نمی‌شود.

صف یعنی ستون N دقیقاً `ONLINE SITE EXISTS - DUPLICATE NAME KEPT` و ستون‌های P و Z خالی. نامزدها با URL ستون O پیدا می‌شوند، نه با کد قرارداد. نبودن ردیف در online به‌معنای نبود فروشگاه آنلاین نیست.

تصمیم‌ها در localStorage همین مرورگر می‌مانند. دکمهٔ «خروجی CSV» یک zip می‌سازد: `general.csv`، یک CSV برای هر وضعیت، و فایل خالی `تغییر نام انجام شد.csv`. میانبر ردیف بعدی: Ctrl+Enter.
