# بررسی فعال‌سازی فروشگاه حضوری

این برنامه روی لپ‌تاپ خودتان اجرا می‌شود و فقط روی `localhost` در دسترس است. برای اجرا نیازی به خرید دامنه یا ساخت سرور نیست.

## اجرا در ویندوز

1. Node.js نسخهٔ LTS را نصب کنید.
2. این پوشه را در Cursor یا ترمینال باز کنید.
3. یک‌بار `npm install` و سپس `npm run dev` را اجرا کنید.
4. در مرورگر خودتان `http://127.0.0.1:3000` را باز کنید.

برای توقف برنامه، در پنجرهٔ ترمینال `Ctrl+C` را بزنید. برنامه روی آدرس محلی bind می‌شود و از شبکهٔ بیرونی قابل بازکردن نیست.

## دسترسی Google Sheets

برای خواندن و نوشتن شیت، یک فایل `service-account.json` در همین پوشه لازم است؛ یا متغیر محیطی `GOOGLE_SERVICE_ACCOUNT_JSON` را تنظیم کنید. فایل کلید را در GitHub یا چت نفرستید؛ `.gitignore` آن را از commit خارج می‌کند. اگر حساب سرویس تازه ساختید، ایمیلش را در `GOOGLE_SERVICE_ACCOUNT_EMAIL` تنظیم کنید و همان حساب را به شیت مبدأ و شیت گزارش دسترسی دهید.

در حالت توسعه، برنامه فقط روی localhost از هویت آزمایشی Cursor استفاده می‌کند. این حالت برای اجرای محلی است و در محیط production پذیرفته نمی‌شود. برای هر میزبانی آینده، ورود امن و فهرست ایمیل‌های مجاز باید پیش از انتشار پیکربندی شود.
